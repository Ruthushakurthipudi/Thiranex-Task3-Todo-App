
# 🚀 Thiranex Task 3 - Interactive To-Do List

A responsive and interactive To-Do List web application developed as part of the Thiranex Internship Task 3: JavaScript Logic & State Management.

This project demonstrates JavaScript DOM manipulation, event handling, CRUD operations, filtering, and browser localStorage for persistent task management.

## 📌 Project Overview

The Interactive To-Do List application allows users to efficiently manage their daily tasks. Users can create, view, update, delete, and mark tasks as completed.

The application uses JavaScript to manage application state and localStorage to retain task data across browser refreshes.

## ✨ Key Features

- ✅ Create new tasks
- 📋 Display and manage tasks
- ✏️ Edit existing tasks
- 🗑️ Delete tasks
- ☑️ Mark tasks as completed
- 🔍 Filter tasks (All, Active, Completed)
- 💾 Persistent data using localStorage
- ⚡ Dynamic DOM manipulation
- 🎯 Event delegation
- 📱 Responsive design for mobile and desktop

## 🛠️ Technologies Used

- HTML5

- Browser localStorage
- DOM Manipulation
- Event Handling

## 🧠 JavaScript Concepts Demonstrated

### 1. CRUD Operations

- Create: Add new tasks
- Read: Display tasks
- Update: Edit and complete tasks
- Delete: Remove tasks

### 2. State Management

Tasks are stored in a JavaScript array and updated whenever the user performs an action.

### 3. Local Storage

The application uses browser localStorage to save task information and restore it when the page is refreshed.

### 4. DOM Manipulation

JavaScript dynamically creates and updates task elements on the webpage.

### 5. Event Delegation

Event listeners on the task list handle actions for dynamically created task elements.
